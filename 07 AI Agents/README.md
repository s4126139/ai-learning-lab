## Learning goals

1. Explain agent loops, tool calls, and the observation returned by each tool.
2. Build a small agent with a limited set of well-defined tools.
3. Test successful actions, tool failures, and cases where the agent should stop.
4. Record evaluation results and operating boundaries before using agent behavior in a larger project.

Apply this work in the [08 Capstone](<../08 Capstone/README.md>).
