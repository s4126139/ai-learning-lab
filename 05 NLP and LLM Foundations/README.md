# 05 NLP and LLM Foundations

**Status: planned.** Use
[Stanford CS224N: Natural Language Processing with Deep Learning](https://web.stanford.edu/class/cs224n/)
as the primary course after [04 PyTorch](<../04 PyTorch/README.md>).

## Learning goals

1. Build a working understanding of word representations and neural NLP models.
2. Explain attention, self-attention, Transformers, and language-model training.
3. Read and implement selected course exercises while documenting assumptions and results.
4. Evaluate language-model outputs and identify common failure modes.

Use these foundations to build and assess systems in
[06 LLM Applications](<../06 LLM Applications/README.md>).
