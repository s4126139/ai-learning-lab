# 04 PyTorch

**Status: planned.** Work through the official
[PyTorch Learn the Basics](https://docs.pytorch.org/tutorials/beginner/basics/intro)
guide after [03 Deep Learning](<../03 Deep Learning/README.md>).

## Learning goals

1. Use tensors, datasets, data loaders, and transforms.
2. Define a model with `torch.nn` and understand automatic differentiation.
3. Train, evaluate, save, and reload a model in a reproducible local workflow.
4. Compare results with a simple baseline and record device, seed, and data setup.

The PyTorch workflow prepares for model exercises in
[05 NLP and LLM Foundations](<../05 NLP and LLM Foundations/README.md>).
