# 08 Capstone

**Status: planned.** Build one end-to-end project that draws on the earlier
stages. A suitable scope is a question-answering assistant over a chosen,
permitted document collection, with optional tool use where it improves a
specific task.

## Project milestones

1. Define users, task, data permissions, success criteria, and a simple baseline.
2. Prepare the data and hold out an evaluation set before tuning the system.
3. Implement retrieval and answer generation; add an agent only for a clear need.
4. Measure quality, grounding, latency, and failure cases against the baseline.
5. Document setup, data provenance, reproducible runs, limitations, and next steps.

Use the [ML lifecycle handbook](<../02 Machine Learning/Machine Learning tổng/README.md>)
to structure the project report. Add code, datasets that may be redistributed,
and results here as the project is built; this README is the project brief.
