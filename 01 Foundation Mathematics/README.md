# 01 Foundation Mathematics

**Status: completed.** The mathematics preparation covers these MIT subjects:

| Subject | Main ideas | Course material |
| --- | --- | --- |
| 18.01 Single Variable Calculus | Derivatives, integrals, and series | [MIT OpenCourseWare 18.01SC](https://ocw.mit.edu/courses/18-01sc-single-variable-calculus-fall-2010/) |
| 18.02 Multivariable Calculus | Partial derivatives, multiple integrals, and vector calculus | [MIT OpenCourseWare 18.02SC](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/) |
| 18.05 Introduction to Probability and Statistics | Random variables, inference, and statistical estimation | [MIT OpenCourseWare 18.05](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/) |
| 18.06 Linear Algebra | Linear systems, vector spaces, eigenvalues, and matrix methods | [MIT OpenCourseWare 18.06SC](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/) |

These completed subjects provide the mathematical basis for optimization,
probabilistic reasoning, and model evaluation in
[02 Machine Learning](<../02 Machine Learning/README.md>). No course notes or
exercise files are stored in this stage yet.
