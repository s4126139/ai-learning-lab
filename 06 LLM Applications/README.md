# 06 LLM Applications

**Status: planned.** Follow the
[DataTalksClub LLM Zoomcamp](https://github.com/DataTalksClub/llm-zoomcamp)
to turn the model knowledge from [stage 05](<../05 NLP and LLM Foundations/README.md>)
into an application.

## Learning goals

1. Build a question-answering workflow over a documented knowledge base.
2. Compare retrieval and generation choices against a simple baseline.
3. Evaluate answer quality, grounding, latency, and failure cases.
4. Keep data preparation, prompts, configuration, and run instructions reproducible.

The application becomes a base for tool-using workflows in
[07 AI Agents](<../07 AI Agents/README.md>).
